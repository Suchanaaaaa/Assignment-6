# 💪 FitLog - Workout Library

## 📖 Project Description

FitLog is a modern workout library web application built with Next.js. Users can browse workouts, view detailed exercise information, add workouts to today's plan, save workouts for later, and track workout statistics through a clean and responsive user interface.

---

## 🛠️ Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React Icons
- React Context API
- Local Storage

---

## ✨ Key Features

### 1. Workout Library
Browse all workouts from the FitLog API in a responsive card layout.

### 2. Workout Details Page
View detailed workout information including equipment, sets, reps, duration, calories, rating, and instructions.

### 3. Today's Plan Management
Add workouts to today's plan and manage daily workout activities.

### 4. Save for Later
Save workouts separately and access them anytime from the My Plan page.

### 5. Dynamic Statistics
Track total exercises, workout duration, and calories burned automatically.
